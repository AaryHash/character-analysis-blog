# A Blog About Character Analysis

## Introduction
This site was developed to practice web design as well as analyze characters in media through a blogging format. There exists a prototype and a final version, with the blog consisting of human-written ideas and reviews.

## Functionality
In order to use this site, open the link (https://aaryhash.github.io/character-analysis-blog/). Choose the "Final" link to see the blog, or the "Prototype" link for its state in an earlier version. Jump between the pages to read my thoughts and view the images I created or found, and interact with the image on the "Example" page to easily jump between different characters to analyze.
